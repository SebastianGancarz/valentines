# 💌 Valentine's Day Website

A small interactive Valentine's Day website created as a fun personal project.

The page asks a simple question — **"Czy mogę zostać twoją walentynką?"** — and reacts differently depending on the user's choice. The "Nie" button tries to escape, while clicking "Tak" triggers a romantic animation with falling hearts. ❤️

## ✨ Features

* 💌 Interactive Valentine's Day question
* 🏃‍♂️ "Nie" button moves to a random position when hovered
* 💬 Question text changes after interacting with the "Nie" button
* ❤️ "Tak" button triggers a special response
* 🐻 Animated GIF displayed on the main page
* 💕 Falling heart animation after accepting
* 📱 Responsive layout for desktop and mobile devices
* 🎨 Custom styling with CSS
* ✍️ Lora Google Font for the main text and buttons

## 🛠️ Technologies

* **HTML5** — page structure
* **CSS3** — styling, layout and animations
* **JavaScript** — interactions and dynamic elements
* **Google Fonts** — Lora font

## 🚀 How to Run

No installation or dependencies are required.

1. Clone the repository:

```bash
git clone https://github.com/your-username/your-repository.git
```

2. Open the project folder.
3. Open `index.html` in your browser.

That's it — the website runs entirely in the browser.

## 🎯 How It Works

When the user tries to interact with the **"Nie"** button, the button moves to a random position on the screen and the text changes.

After several interactions, the **"Nie"** button disappears completely.

Clicking **"Tak"** changes the image and message and starts generating animated hearts across the screen.

## 📱 Responsive Design

The website uses responsive CSS properties such as:

* `max-width`
* `vw`
* `clamp()`
* flexible positioning

This allows the page to work on both desktop and mobile screens.

## 💡 Purpose

This project was created as a small example of using **HTML, CSS and JavaScript together** to create an interactive web experience.

It is intentionally simple and focuses on DOM manipulation, event handling, CSS animations and responsive design.
